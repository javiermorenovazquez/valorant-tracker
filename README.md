# 🎯 Valorant Tracker

Aplicación web para **registrar partidas de Valorant y analizar tu rendimiento**, hecha con **HTML, CSS y JavaScript puro** (sin librerías ni frameworks).

🔗 **Pruébala:** https://javiermorenovazquez.github.io/valorant-tracker/

## Funcionalidades
- Formulario con validación para añadir partidas (mapa, agente, resultado, K/D/A, ACS y % de headshot).
- Panel de estadísticas: % de victorias, K/D, KDA, ACS medio y % de headshot, comparados con las últimas 5 partidas.
- Gráficas dibujadas a mano con `<canvas>`: evolución del K/D y % de victorias por mapa.
- Análisis automático: mejor y peor mapa, agente más fiable y tendencia reciente.
- Historial con filtros por mapa, agente y resultado, y columnas ordenables.
- Datos guardados en el navegador con `localStorage`, y exportación e importación en JSON.
- Diseño adaptable a móvil.

## Tecnologías
`HTML5` · `CSS3 (Grid, Flexbox, variables)` · `JavaScript ES6+` · `Canvas API` · `localStorage`
